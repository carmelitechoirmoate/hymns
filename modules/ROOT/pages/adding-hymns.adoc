= Adding a Hymn
:!page-pagination:

Everything on this site is a plain text file in the GitHub repository https://github.com/carmelitechoirmoate/hymns[carmelitechoirmoate/hymns^].
You can do all of this in a web browser on github.com, signed in as *carmelitechoirmoate*.
The site rebuilds by itself a minute or two after each change.

== Fix a typo

Open the hymn on this site and use *Edit this Page* at the top right.
GitHub opens the file, you make the change, then press *Commit changes*.

== Add a hymn

. In the repository, open the folder `modules/ROOT/pages/hymns`.
. Choose *Add file > Create new file*.
. Name it after the hymn, in lower case with dashes, ending in `.adoc`, for example `lord-of-the-dance.adoc`.
That name becomes the web address, so don't change it later.
. Paste in the template below and fill it in.
. Press *Commit changes*.

The hymn appears in *Hymns A to Z*, in the menu and in search automatically.

----
= Lord of the Dance
:composer: Sydney Carter
:hymnal-page: 312
:key: F
:season: Easter, Any time
:mass-part: Recessional
:sheet-music:
:youtube: https://www.youtube.com/watch?v=...
:audio:
:hardbreaks-option:

*1.* I danced in the morning
when the world was begun,
...

_Refrain_
Dance, then, wherever you may be,
...
----

What each line means:

[cols="1,3"]
|===
|`=` line |The title, exactly as it should be shown.
|`:composer:` |Who wrote the words and music. Leave blank if you don't know.
|`:hymnal-page:` |The page or number in the hymn book.
|`:key:` |The key the choir sings it in.
|`:season:` |One or more, separated by commas. Use the same names as other hymns so the filter groups them: _Advent, Christmas, Lent, Easter, Pentecost, Ordinary Time, Marian, Any time_.
|`:mass-part:` |One or more, separated by commas: _Entrance, Gloria, Responsorial Psalm, Gospel Acclamation, Offertory, Communion, Reflection, Recessional, Benediction, Marian procession_.
|`:sheet-music:` |The picture file(s) of the music, separated by commas (see below). Leave blank if there is none.
|`:youtube:` |Links to performances on YouTube, separated by commas. Without one, the page shows a YouTube search link instead.
|`:audio:` |Sound files shared by the choir (see below).
|`:hardbreaks-option:` |Leave this in: it keeps each line of the lyrics on its own line.
|===

For the lyrics, type each line on its own line and leave a blank line between verses.
Start a numbered verse with `\*1.*`, `\*2.*` and so on (with the stars, so the number shows in bold).
Put labels such as `\_Refrain_` or `\_Ladies_` between underscores to show them in italics.

== Add sheet music

. Take a clear photo or scan of the music, ideally upright and cropped.
. Open the folder `modules/ROOT/images/sheet-music` and choose *Add file > Upload files*.
Name the file after the hymn, for example `lord-of-the-dance.jpg`.
. In the hymn file, set `:sheet-music: lord-of-the-dance.jpg`.
For two pages: `:sheet-music: lord-of-the-dance-1.jpg, lord-of-the-dance-2.jpg`.

The hymn page then shows a *Lyrics / Sheet music* switch.

== Add a recording

Save the voice note or sound file from WhatsApp (an `.mp3`, `.m4a` or `.opus` file), upload it to `modules/ROOT/attachments/audio`, and set, for example, `:audio: lord-of-the-dance-altos.m4a`.
A player appears under *Listen* on the hymn page.

== Record what we sang on a Sunday

. Open the folder `modules/ROOT/pages/sundays` and create a new file named with the date, for example `2026-12-06.adoc`.
. Paste this in and change it:
+
----
= Sunday 6 December 2026
:date: 2026-12-06
:occasion: 2nd Sunday of Advent

* Entrance: xref:hymns/christ-be-our-light.adoc[]
* Offertory: xref:hymns/as-gentle-as-silence.adoc[]
* Communion: xref:hymns/holy-is-his-name.adoc[]
* Recessional: xref:hymns/hail-queen-of-heaven.adoc[]
----
+
The part after `hymns/` is the hymn's file name.
Something that isn't on the site yet, such as a Mass setting, can be typed as plain text: `* Mass setting: Bodley Mass`.

The date then appears in *What we sang*, on the home page if it is the newest, and under *Sung on* on each hymn's page.
